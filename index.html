0ms Read / Write Latency

Zero Wi-Fi? No spinning loading wheels.

Most student apps hang or lock up the moment connectivity drops in basement auditoriums. Notlyfe writes directly to local Apache Hive boxes in memory. You can draft 3,000 words of notes, organize course lectures, and edit todos without a single packet of internet.

DEEP ARCHITECTURE

Every feature built with intention.

Grounded utility tailored for engineers. Zero cartoon radius, zero bloated analytics tracking.

Semester Course Catalog & Lab Tracker

Organize complex subjects like Computer Networks, Database Systems, Data Structures, and Web Engineering with designated credit hours, syllabus progress, and lab assignment submissions.

  • Instant assignment checklist with deadlines and notification reminders
  • Lab code snippets and markdown formatted technical notes

Apache Hive Engine

Embedded key-value boxes written in pure Dart. No SQLite bridge overhead, no database locks, and instant serialization.

Benchmark: 0.38ms read latency

Weighted CGPA Engine

Supports standard university 4.00 grading matrices. Accurately weights multi-semester credits without inaccurate linear assumptions.

Encrypted Supabase Cloud Backup

Synchronize your local Hive boxes to encrypted Supabase PostgreSQL with Row Level Security (RLS). If you switch or misplace your phone, your notes and academic trajectory remain 100% intact.

  • Automated background reconciliation when network is re-established
  • Encrypted user token authorization with PostgreSQL RLS isolation
